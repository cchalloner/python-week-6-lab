# Week 6 Lab: Lists and f-strings

## Setup
1. Open this folder in VS Code.
2. Open `week6_lab.ipynb`.
3. Select the Python kernel if prompted.
4. Complete each task directly in the notebook. Full task instructions and grading details are posted in Blackboard.

## Submitting Your Work
1. Run all cells top to bottom to confirm your code works before submitting.
2. Open the Source Control panel in VS Code (branch icon).
3. Stage your changes (+).
4. Commit with a message such as: `feat: Complete Week 6 lab`
5. Sync (push) your changes to GitHub.
6. Copy your repository URL and paste it into the Week 6 Lab assignment in Blackboard.
